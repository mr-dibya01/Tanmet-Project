# Tanmet Technologies – Company Website

This repository contains the source code for the official company website of **Tanmet Technologies Pvt Ltd**.

---

## 🔹 Project Overview

A modern, responsive, single-page company website built with a clean UI and basic SEO optimization.

---

## 🔧 Tech Stack

- React.js  
- Tailwind CSS  
- GitHub (Version Control)

---

## ✨ Features

- Fully responsive design (Mobile, Tablet, Desktop)
- Modern UI with smooth scrolling
- Basic SEO optimization (meta tags, headings, Lighthouse SEO 100)
- Clean and maintainable code structure
